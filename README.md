# DARK SCHOOL — لعبة رعب ثلاثية الأبعاد في المتصفح

لعبة رعب بمنظور الشخص الثالث تدور داخل مدرسة مظلمة. الأستاذ كريم كان معلّمًا طيبًا، وبعد وفاة زوجته ليلى تحوّل حزنه وغضبه إلى كابوس يطارد الطلاب. أنت طالب (عمر) بقي في الاحتجاز وعليك كشف أسرار المدرسة والهروب منها — أو إنهاء الكابوس.

> **A 3D third-person horror game for the browser** built with HTML + CSS + JavaScript + **Three.js**. No Unity / Godot, no external art or audio files: characters, textures, sounds and music are generated procedurally at runtime.

---

## 1) الملفات

| الملف | الدور |
|---|---|
| `index.html` | هيكل الصفحة: القوائم، الـHUD، النوافذ المنبثقة، أزرار اللمس |
| `style.css` | التصميم، دعم RTL/LTR، الهواتف، تأثيرات الشاشة |
| `game.js` | كل منطق اللعبة (مقسّم لأقسام مرقّمة 0–10 في رأس الملف) |
| `.github/workflows/deploy.yml` | نشر تلقائي على GitHub Pages |

أقسام `game.js`: الأدوات والإعدادات ← محرك الصوت (WebAudio) ← المُصيِّر والجودة والتركيبات ← عالم التصادم وخط الرؤية وشبكة الملاحة (A*) ← بناء المدرسة ← الشخصيات والحركات ← اللاعب والكاميرا ← ذكاء الأستاذ ← منطق اللعبة والألغاز والنهايات ← الواجهة ← الحلقة الرئيسية والترجمة.

## 2) التشغيل محليًا

المتطلبات: Node.js 18+ .

```bash
npm install          # يثبّت Three.js وأدوات البناء
npm run dev          # تطوير: افتح الرابط الذي يظهر (مثلاً http://localhost:5173)
npm run build        # بناء نهائي → dist/index.html (ملف واحد يحتوي كل شيء، يعمل دون إنترنت)
npm run preview      # معاينة نسخة البناء
```

> يمكن أيضًا تشغيل الملفات الثلاثة الخام (`index.html` + `style.css` + `game.js`) على أي خادم ثابت مباشرةً: `index.html` يحتوي على *import map* يحمّل Three.js من CDN. افتحها عبر خادم (مثل `npx serve .`) وليس بالنقر المزدوج، لأن وحدات ES لا تعمل من `file://` في بعض المتصفحات.

## 3) النشر على GitHub Pages — خطوة بخطوة

### الطريقة أ: تلقائيًا عبر GitHub Actions (موصى بها)
1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه كل ملفات المشروع (`git init && git add . && git commit -m "DARK SCHOOL" && git branch -M main && git remote add origin <رابط المستودع> && git push -u origin main`).
2. في المستودع: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. أي دفع (push) إلى فرع `main` يشغّل `.github/workflows/deploy.yml` الذي ينفّذ `npm ci && npm run build` ثم ينشر مجلد `dist`.
4. بعد دقيقة تقريبًا يظهر الرابط في تبويب **Actions** وفي **Settings → Pages**: `https://<اسمك>.github.io/<المستودع>/`.

> لا حاجة لضبط `base` في Vite: ملف البناء النهائي يضمّن (inline) الجافاسكربت والـCSS داخل `index.html`، فلا توجد مسارات نسبية قد تنكسر على صفحات المشاريع.

### الطريقة ب: يدويًا
1. نفّذ `npm run build`.
2. انسخ `dist/index.html` وحده إلى فرع `gh-pages` (أو مجلد `/docs`) وفعّل Pages من **Settings → Pages → Deploy from a branch**.

### الطريقة ج: دون أي بناء
ارفع `index.html` و`style.css` و`game.js` في جذر الفرع `main` وفعّل **Deploy from a branch → main / (root)**. تحتاج اتصال إنترنت لأن Three.js يُحمَّل من CDN.

## 5) ما الذي تحتويه اللعبة

- **مدرسة كبيرة** من طابقين (أرضي + قبو بسلم حقيقي): 3 صفوف، مكتبة، مختبر، مكتب مدير (بقفل رقمي)، غرفة معلمين، عيادة، غرفة حارس، كافتيريا، دورة مياه، موسيقى، فنون، ممران، بهو، وفي القبو: كهرباء، غلاية، أرشيف، مخزن، صيانة، ومقام سري. **غرفتان سريتان** (خلف رف المكتبة، وغرفة المقام بقفل مغناطيسي).
- **الأستاذ كريم**: مجسم مفصلي مرعب (جسد نحيل منحنٍ، عينان متوهجتان، وجه مرسوم، عصا) بحركات: مشي، ركض، بحث، صراخ، ضربة. ذكاء اصطناعي كامل: دورية بين الغرف ← يسمع الضجيج (الركض، الأبواب، الرموز الخاطئة، الهبوط من القفز) ← يرى اللاعب بمخروط رؤية وخط نظر يحترم الارتفاعات (الانحناء خلف الأثاث العالي يخفيك) وعدّاد انتباه تدريجي ← مطاردة بمسارات A* وفتح الأبواب ← فقدان الأثر والبحث عند آخر موقع ← تفتيش الخزائن القريبة ← العودة للدورية.
- **حركة الطالب**: مشي، ركض (تحمّل)، قفز (يمكن الصعود على المكاتب)، انحناء، اختباء داخل الخزائن مع **كتم النفس**.
- **مهمات وألغاز**: مصباح وبطارية تنفد، 4 مفاتيح، باب سري بكتاب أحمر، رمز رقمي مستنتج من القصة ومن ساعة الممر، فيوزات وصندوق كهرباء، إنذار ومطاردة غاضبة عند أخذ مفتاح البوابة.
- **أجواء**: إضاءة متقطعة (تتأثر بقرب الأستاذ)، انقطاعات كهرباء، ضباب، ظلال المصباح، موسيقى ونبض قلب وأصوات مولَّدة بالكامل (WebAudio) مع صوت مكاني، مفاجآت مدروسة (باب يُصفق، سبّورة تكتب، بيانو، همسات، صندوق موسيقى).
- **نهايات متعددة**: *الليلة الطويلة* (هروب، بنسختين حسب معرفتك بالحقيقة)، *وداعًا يا ليلى* (إعادة الخاتم بعد جمع ≥ 6 من 8 صفحات — يمكن أيضًا عند الإمساك بك)، *رماد* (إفراط ضغط الغلاية). ويُحفظ ما اكتشفته منها.
- **حفظ تلقائي** في `localStorage` (نقاط حفظ عند الالتقاط/الفتح/كل 45 ثانية في الهدوء) + متابعة + إعادة من آخر نقطة.
- **اللغتان**: العربية (RTL كامل) والإنجليزية بزر تبديل فوري.
- **الأداء**: دمج الهندسة الثابتة في دفعات لكل مادة/قطعة (frustum culling)، مجموعة ثابتة من الأضواء الحقيقية تتبع أقرب التجهيزات، أضواء السقف عبر `InstancedMesh`، مواد Lambert في وضع الجودة المنخفضة، ظلال المصباح (إيقاف/512/1024/2048)، مقياس الدقة، **دقة تكيفية** تخفض الدقة تلقائيًا عند هبوط الإطارات، وإعادة استخدام الكائنات دون تخصيص ذاكرة في كل إطار.

## 6) ملاحظات صريحة عن الأصول

- **لا توجد ملفات أصول خارجية**. الشخصيات هي هياكل مفصلية (hierarchy of joints) ببنية جسم كاملة (رأس، رقبة، عمود فقري، أذرع بمرفقين، أرجل بركبتين) تُحرَّك بـ`THREE.AnimationMixer` وكليبات مفاتيح (keyframes) حقيقية مع مزج بين الحركات — لكنها مبنية من أشكال ناعمة (كبسولات/كرات) مولّدة بالكود وليست نماذج GLTF منحوتة في برنامج نمذجة. إن أردت استبدالها بنماذج GLB مرخّصة (مثل CC0 من Quaternius أو Kenney)، ضع الملف في `public/` وحمّله بـ`GLTFLoader` داخل `buildStudent()` / `buildProfessor()` مع الإبقاء على نفس أسماء الكليبات (`idle, walk, run, ...`).
- الخطوط (Cairo / Special Elite) تُحمَّل من Google Fonts إن توفّر الإنترنت، وإلا تُستخدم خطوط النظام.
- Three.js بترخيص MIT.
- همسات الأستاذ الصوتية تستخدم `speechSynthesis` المدمج في المتصفح فقط إن وُجد صوت للغة المختارة (يمكن إيقافها من الإعدادات).
